【audio フォルダの使い方】（電車でGO！ 大網特快）

■ 置き場所
  GitHub Pages のリポジトリで、index.html と同じ階層に「audio」フォルダを作り、
  下の表のファイル名で音声をアップロードするだけで、ゲーム起動時に自動で読み込まれます。
  （ファイル名は小文字・半角。GitHub Pages は大文字小文字を区別します）
  対応形式: mp3（既定）。ほかの形式(ogg/wav/m4a)は下の manifest.json で指定します。

■ 優先順位
  ① アプリの「音の設定」でこの端末に選んだ音  ＞  ② audio フォルダの音(📁)  ＞  ③ 内蔵音
  ※VVVF加速音・すれ違い音・走行音は差し替え対象外です（内蔵の合成音のまま）。
  ※音声ファイルが無い項目は、これまで通りの内蔵音／音声読み上げが鳴ります。

■ ファイル名一覧
  [車両・走行音]
   horn.mp3        警笛（押している間ループ）
   joint.mp3       レール継ぎ目の音（継ぎ目ごとに1回再生）
   brake.mp3       ブレーキ緩解音
   cross.mp3       踏切の警報音（ループ）
  [警告音]
   ovsp.mp3        速度超過の警告音
   ats.mp3         ATS作動音
   slip.mp3        空転の警告音
   hazard.mp3      前方支障の警報音
  [ドア・発車メロディー]
   open.mp3        ドアが開く音
   close.mp3       ドアが閉まる音
   melody_all.mp3  全駅共通の発車メロディー
   melody_0.mp3 〜 melody_7.mp3   駅ごとの発車メロディー（駅番号は下記）
  [車内放送]（置くと音声読み上げの代わりに再生。画面の文字はそのまま出ます）
   chime.mp3       車内チャイム（各放送の前に鳴らす）
   a_start.mp3     運転開始「この電車は、大網特快、大網行きです」
   a_next.mp3      出発後「次は、○○」        駅別: a_next_1.mp3 など
   a_mid.mp3       途中の案内                  駅別: a_mid_0.mp3 など（出発した駅の番号）
   a_approach.mp3  「まもなく、○○」           駅別: a_approach_1.mp3 など
   a_exit.mp3      「お出口は、○○側です」     駅別: a_exit_1.mp3 など
   a_arrive.mp3    到着「○○、ご乗車ありがとうございます」 駅別: a_arrive_1.mp3 など
   a_door.mp3      「ドアが閉まります」         駅別: a_door_1.mp3 など
   a_ats.mp3       「急停車します」
   ※駅別ファイル(a_xxx_番号.mp3)があればそれを優先、無ければ共通(a_xxx.mp3)を使います。

■ 駅番号
   0 東京 / 1 錦糸町 / 2 船橋 / 3 千葉 / 4 蘇我 / 5 鎌取 / 6 土気 / 7 大網
   （a_next_1 は「次は錦糸町」、a_arrive_2 は「船橋に到着」の放送）

■ 別の形式・別の名前を使いたいとき（任意）
   audio/manifest.json を作り、ファイル名を指定します（manifest.sample.json を参考に）。
   （_probe は現在は無視され、manifest に無いファイルも既定名で探します）
   ハイフン区切りの名前（a-next-1.mp3 など）や、拡張子が二重の名前（a_next_1.mp3.mp3）も読み込みます。音の設定の画面で、読み込めたファイルを確認できます。

■ 更新が反映されないとき
   アプリはオフライン用に音声もキャッシュします。差し替えたら sw.js 内の
   CACHE の番号（例: oami-tokkai-v24 → v25）を上げてアップロードし、アプリを再読み込みしてください。
   なお、置いていないファイルへのアクセスは 404 になりますが、ブラウザのコンソールに出るだけで問題ありません。
